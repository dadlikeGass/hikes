# 全站视觉重整方案 · 山野路簿

## 目标
让用户在山上快速辨认地点、读懂路线、完成到访；在桌面上能舒适浏览和比较。保留现有数据、内容和操作路径。

## 设计方向
- 概念：一册持续由山友补写的山野路簿。路线是线，山峰与岔路是点，到访是盖章。
- 颜色：浅岩纸 `#f5f3eb`、深松绿 `#193f3a`、苔绿 `#5b7d68`、朱砂橙 `#e46b47`、深墨 `#1d2d2a`。
- 字体：正文优先系统中文无衬线；标题使用项目已有字库的可用字形并回退到系统重字重。保持文字为 HTML。
- 构图：手机单列，桌面内容上限 1160px；路线列表多列，详情阅读区限制宽度；导航桌面横向、手机底部固定。
- 图片：首页保留山景插画。路线和地点页使用真实轨迹/海拔与既有景观，不新增臆造地貌图。
- 交互：每屏一个主动作；扫码与到访用朱砂橙，次要动作弱化；频繁操作只做短促按压反馈。

## 页面批次
1. 全站框架：背景、字体层级、导航、按钮、卡片、表单、状态。
2. 路书与山头／岔路列表：筛选、卡片密度、路线和地点识别。
3. 路线、山峰、岔路详情与扫码：首屏地点与主要动作优先，说明与社区内容随后。
4. 消息与我的：任务和记录优先，贡献与维护信息分层。
5. 关键页面在 390px 和 1440px 两端截图检查，修正溢出和层级问题。

## 验收
所有现有路由可打开；手机无横向溢出；桌面不再是手机外框；底部安全区不遮挡操作；文字与按钮对比度清楚；现有数据与交互不变。
