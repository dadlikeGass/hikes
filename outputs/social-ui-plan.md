# 山里见：扫码户外社交网站 UI 方案

定位：真实地点里的到访、留言和人与人的连接。扫码为主入口，路书与难度为信任基础。

## 导航
山友圈 / 想来 / 扫一扫 / 消息 / 我。

## 首页从上到下
1. 品牌、通知；简短欢迎。
2. 主行动：扫一扫，留下我来过；桌面展示手机扫码入口或输入点位编号。
3. 个人摘要：想来、来过、拼图进度。
4. 山友动态 / 我的关注：到访照片卡、首次成就、里程碑；可击掌、留言、收藏地点。
5. 留给下一位：展示玩法及公开预览，现场扫码拆开当地留言。
6. 拼图进度、趣味用时榜：轻量次入口，不抢占动态主体。
7. 手机底部五项导航。

## 扫码到达页
地点与路书入口 → 我来过 → 编号纪念与个人第一次 → 入口至终点用时 → 留言惊喜 → 留言墙 → 求合影/同行 → 写给未来自己的信。
先让用户轻量打卡，再展示适合的惊喜；不一次弹出九个窗口。

## 九个玩法的位置
17 山径拼图：我 / 收藏册；到达新点位解锁，首页显示进度。
16 用时榜：点位内，入口开始/终点结束；好友榜、今日榜、个人记录。
15 未来信：到达页写信，我 / 山间信箱；按日期或下次到访解锁。
13 拍照/同行：点位现场短时请求，回复进入消息。
10 第N位：到访卡及点位热度，百位里程碑特别庆祝。
9 第一次：到访后自选标签，生成专属卡，其他人可祝贺。
7 下一位留言：点位惊喜卡，拆信、回应、留给下一位。
4 到访纪念卡：打卡完成后的主要结果，分享至动态或保存。
1 留言墙：每个点位固定入口，按新鲜/热门查看并回复具体用户。

## 页面树
山友圈：动态详情 → 地点空间 → 留言墙 / 用时榜 / 现场小请求 / 路书。
想来：已收藏地点 → 地点空间；到访后成为来过记录，可继续保留复访愿望。
扫一扫：点位识别 → 到达页 → 昵称打卡 → 纪念卡 → 惊喜/互动。
消息：回复与击掌 / 请求回应 / 信件解锁 / 好友互动。
我：到访卡 / 第一次 / 山径拼图 / 用时记录 / 山间信箱 / 个人资料。
维护后台：地点与路线、二维码点位、分级与路书、内容和维护记录。

## UI
背景暖白 #F8F4ED；品牌钴蓝 #3455F5；主庆祝色珊瑚橙 #FF714E；墨色 #222333；淡紫用于信件。
卡片像明信片与印章，照片和人像承担情绪。绿色只可用于简单路线的难度标识，不用作品牌色。
难度绿圆/黄方/红菱形保持原定映射；网页内仅在路线资料区域展示。
首屏强调人、动作与现场；避免大幅营销横幅和路线参数列表。

## 设计状态
此为概念 UI 与示例数据，不是已上线服务。效果图由内置 imagegen 生成，提示核心：暖白/钴蓝/珊瑚橙、双移动页面、山友动态首页与扫码到达页、九项选定玩法。
