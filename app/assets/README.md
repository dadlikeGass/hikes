# 到此一游视觉素材

## 文件

- `brand/logo-mark.svg`：彩色山形标识，可单独使用。
- `brand/logo-lockup.svg`：山形与「到此一游」组合预览。网站实际字标使用 HTML 文字与系统中文字体，避免 SVG 在不同系统上缺字或字形变化。
- `icons/mountain.svg`、`book.svg`、`scan.svg`、`chat.svg`、`user.svg`：24 × 24 线框图标，1.8 线宽，圆角端点。页面内联 SVG 路径与此处相同，颜色由 CSS 控制；独立文件提供给设计稿、印刷或其他客户端。
- `decor/sun.svg`、`pink-underline.svg`：首页装饰。
- `../images/home/mountain-landscape.png`：可响应式裁切的山景主视觉。
- `../images/home/hiker.png`：透明背景徒步者插画。

## 字体

标题与正文统一使用系统中文字体栈：PingFang SC → Noto Sans CJK SC → Microsoft YaHei。字标使用同一字体栈的重字重。项目已有的 Zhi Mang Xing 子集字体仍用于原有特定字形，但因只包含少数字符，不用作通用标题或正文。页面文字均保留为可选中、可缩放的网页文字。

## 颜色

天蓝 `#c5ecfc`，亮粉 `#ff5298`，青绿 `#39a875`，深色文字 `#25283b`。SVG 图标默认中性灰，实际页面状态色由 CSS 覆盖。
